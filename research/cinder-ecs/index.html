Cinder ECS

Cinder ECS is a small entity component system library I wrote for Cinder. Its main focus is to provide a simple API for composing objects and traversing data. It is a learning project and not meant for production use.

Traditional ECS libraries work well in game-like environments, where most objects can be described by components and their behaviour by systems. In creative coding it is common to have entities with very specialized behaviour that break that mindset, so this library tries to fix that by not enforcing very strict rules.

On top of the core it ships with a few features that are useful in a day-to-day creative coding environment: a transform system, a button system (mouse click), draw targets and a naive serialization mechanism for saving and loading scenes.

Technical Write Up

The Manager is the central class that stores all entities, components and systems. It is hooked into the Cinder setup, update and draw calls and is used to create entities and systems.

Components are plain structs. When added to an entity they are stored in the manager, so all components of the same type live next to each other in memory and can be iterated efficiently. The entity only holds a raw pointer. Entities can also be queried by a component mask. 

auto e = mManager.createEntity();
e->addComponent<ColorComponent>();
e->getComponent<ColorComponent>()->mColor = Color::gray(0.5f);

for( auto& e : mManager.getEntitiesWithComponents<ColorComponent, RectComponent>() ){
    e.getComponent<ColorComponent>()->mColor = Color(1.0f, 0.0f, 0.0f);
}

Not everything has to be a bag of components. A scene is typically a one-off object with lots of specialized behaviour, so it is more straightforward to extend the Entity class directly and mix it with component based entities like buttons. 

struct Scene : public ecs::Entity {
    void setup() override { /* add transform, etc. */ }
    void animateIn();
    void animateOut();
};

auto scene = mManager.createEntity<Scene>();

Systems are the only objects that get update and draw called every frame, which makes them a good fit for updating a batch of components together, like a particle system.

Draw Targets

Draw targets allow entities to be rendered into FBOs, scissored scenes and post processing chains.

Interaction

The button system handles mouse interaction and callbacks, and works together with the transform hierarchy.
